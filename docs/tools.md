# FitNesse MCP – tools, gates and descriptions (66)

Gates: mode (read/write/test) must be in FITNESSE_TOOLSETS; area complete/debug must be named as well; extra env gates as listed.


## standard

| Tool | Mode | Extra gate | Description |
|---|---|---|---|
| `fitnesse_compare_history` | read | – | Generates a report comparing two test result files for a page history responder call. |
| `fitnesse_compare_versions` | read | – | Shows the differences between two saved versions of a page, or between one version and the latest when only one is given. Version ids as listed by fitnesse_get_versions. Returns HTML. |

Pass both to fitnesse_save_page_content when saving changes based on this text: if someone else saved the page in between, the save fails instead of overwriting their change. |
| `fitnesse_get_page_history` | read | – | Displays test history for a page with optional resultDate selector. Returns XML. |
| `fitnesse_get_properties` | read | – | Displays the properties form for the selected page. Returns JSON. |
| `fitnesse_get_rss` | read | – | Returns an RSS feed for the current page and all of its children. |
| `fitnesse_get_suite_overview` | read | – | Shows the test pages of a suite as a tree with their latest results, without running anything. Takes the same test selection as fitnesse_run_suite. Returns HTML. |
| `fitnesse_get_variables` | read | – | Returns the variables available on the selected page context. |
| `fitnesse_get_versions` | read | – | Returns the versions view that lists saved versions for the selected wiki page. |
| `fitnesse_list_files` | read | FILES_ROOT | Displays a directory listing in the files section for the selected files resource. Returns result as JSON. |
| `fitnesse_list_names` | read | – | Lists page names at the current level and supports Recursive, LeafOnly, ShowTags, and ShowChildCount. Returns JSON. |
| `fitnesse_search` | read | – | Searches pages for searchString in page names (search_type='title') or page content (search_type='content'). Text search is plain text, not a regex. method_search=true (content only) finds pages using a method or scenario: give a wiki line that evaluates to it, e.g. '\|click\|x\|'. Searches page_path and its children, unless search_scope names an ancestor page or 'root' for the whole wiki. Returns an HTML table of matches. |
| `fitnesse_view_version` | read | – | Shows a selected saved page version identified by the version file id. |
| `fitnesse_run_suite` | test | – | Runs all tests below the selected page. Select tests with tags (suite_filter / run_tests_matching_any_tag: any of the tags, the latter wins; run_tests_matching_all_tags; exclude_suite_filter), first_test, or a partition (partition_count + zero-based partition_index; preview with fitnesse_partition_preview). Returns XML unless format says otherwise. Do not combine nohistory with format='xml': the XML report is built from the history. |
| `fitnesse_run_test` | test | – | Runs a test page and supports debug, remote_debug, nochunk, nohistory, and markup variable inputs. Returns XML unless format says otherwise. |
| `fitnesse_stop_test` | test | – | Stops running tests, either all active tests or one process when id is provided. |
| `fitnesse_add_child_page` | write | – | Creates a new child page beneath the selected page using pageName and pageContent, with optional pageTemplate, pageType, help text and tags (suites). |
| `fitnesse_create_dir` | write | FILES_ROOT | Creates a new directory in the files section below the given resource using dirname. |
| `fitnesse_delete_file` | write | FILES_ROOT | Deletes a file from the files section directory identified by the resource and filename. |
| `fitnesse_delete_page` | write | – | Deletes the specified page. |
| `fitnesse_import_and_view` | write | – | Imports a page hierarchy if needed and then views the selected page. |
| `fitnesse_import_pages` | write | – | Imports a page hierarchy from a foreign FitNesse using remoteUrl with optional credentials and autoUpdate. |
| `fitnesse_manage_symlink` | write | – | Creates, removes, or renames symbolic links between pages using removal, rename, newname, linkName, and linkPath. |
| `fitnesse_move_page` | write | – | Moves the selected page below a different parent page using newLocation. |
| `fitnesse_purge_history` | write | – | Purges test history files older than `days` for the selected page and its children; purge_global=true purges the history of all pages instead. |
| `fitnesse_rename_file` | write | FILES_ROOT | Renames a file in the files section using filename and newName within the selected directory. |
| `fitnesse_rename_page` | write | – | Renames the selected page using newName and does not perform page moves. |
| `fitnesse_replace` | write | – | Replaces text in the selected page and all its children and saves every changed page; returns an HTML table of the changed pages. Text replace: search_string is a regular expression. method_replace=true: search_string is a wiki line that evaluates to a method or scenario (e.g. '\|click\|x\|'). search_scope limits it to an ancestor page or 'root'. Try the search with fitnesse_search first: this cannot be undone in one step. |
| `fitnesse_rollback_version` | write | – | Rolls back a page to a selected version identifier from saved versions. |
| `fitnesse_save_account` | write | ALLOW_ACCOUNT_ADMIN | Changes FitNesse accounts (responder=saveAccount), as the account this server logs in with. action='change_password': new password for that account (current_password, new_password). 'create_user' and 'delete_user' need the admin user: user_name, plus user_password for create_user. Only on explicit request. |
| `fitnesse_save_page_content` | write | – | Saves wiki page content via POST using pageContent and optional editTime, ticketId, and redirect fields. FitNesse removes the page's help text and tags when they are not sent, so help_text and suites are kept from the current page unless given; pass an empty string to remove them. Without edit_time the save overwrites the page (last write wins). With edit_time and ticket_id (from fitnesse_get_page_data) FitNesse checks for a conflict: if someone else saved the page since then, nothing is saved and the tool fails; re-read the page, merge, and save again. |
| `fitnesse_save_properties` | write | – | Saves page properties via POST: pageType, attribute flags, Suites tags and HelpText. FitNesse resets every attribute that is not sent, so each argument left out keeps the page's current value; `attributes` is the complete list of flags that end up set. Pass an empty string or list to clear a value. |
| `fitnesse_shutdown` | write | ALLOW_SHUTDOWN | Shuts the FitNesse server down through the shutdown responder. |
| `fitnesse_upload_file` | write | FILES_ROOT | Uploads file content into the files section directory selected by the resource path. Pass text content directly via `content`, or binary/base64-encoded content via `content_base64`. |

## debug

| Tool | Mode | Extra gate | Description |
|---|---|---|---|
| `fitnesse_debug_defined_action_source` | read | – | Reads the current wiki of a defined action for editing: finds the page that defines it via the session's defined actions, reads that page fresh (not what the session loaded) and cuts out the definition block as FitLibrary reads it: the header table (the page's first table or the first after a ---- line) and every table up to the next ----, with the text in between. Forks with definedAction pick the definition as a run would (keywords, number of arguments, loaded last wins). Result: page, index, last, original, ready for fitnesse_table_save(page_path=page, index=index, last=last, original=original, wiki=<new>, reload_defined_actions=true). On older forks it fails if the header is on the page more than once. Needs a debug session in which the action is loaded, or page_path, the defining page. |
| `fitnesse_debug_inspect` | read | – | Looks into the debug session. kind: - 'keywords': the keywords you can use in tables right now. Without filter: only the categories with their number of keywords (the full list is large). With filter (a word such as 'click', or a category such as 'Web / Browser'): matching entries in full: syntax, where %1, %2 are the cells for parameters (e.g. 'click %1' -> '\|click\|//button\|'), parameters (label, allowed options), returnType, tableItems (the rows a keyword expects in the rest of its table; 'This statement is mandatory' in helpText marks required rows) and helpText. Defined actions are not in it: see 'definedActions'. - 'definedActions': the defined actions loaded in this session by \|define actions at\| (usually from SetUp): action (call syntax, parameters as cells), parameters, note, deprecated, author, page (where it is defined; edit it with fitnesse_debug_defined_action_source) and overrides. filter searches all fields. Empty until the page's 'define actions at' tables have run in the session. - 'dynamicVariables': variables set during the test (name, value); include_system adds the many unchanged Java system properties. - 'scope': the objects whose keywords are available, innermost first (level, name, class, depth). - 'liveView': the Selenium grid session of the open browser and live_view_url, a link where a person can watch the browser (password not included). |
| `fitnesse_debug_page_tables` | read | – | Lists the tables that running a page executes, in order, including those of its SetUp/TearDown and included pages: index, number of rows and the first row. Use the indices to run only some of them with fitnesse_debug_run_page(tables=[...]); setup_tables are those of the SetUp (what run_page(setup_only=true) runs). These indices differ from fitnesse_table_source's, which counts only the page's own tables: to edit a table, use its source_page and source_index with the fitnesse_table_* tools. A table of an included page (included=true, e.g. SetUp) is edited on that page, which changes it for every page that includes it. Requires a debug session; omit page_path for the page currently being tested. |
| `fitnesse_debug_status` | read | – | Shows the debug session of this FitNesse account and the new lines of the test process log since the last call. Answers immediately, even while another call is still running a long table, so use it to watch progress. Result: running (false = no session), page (where the session was started), currentPage (whose test is running), suite, busy, idleSecondsLeft (the session ends itself after this idle time), known_to_this_server, and log.lines ('time [out\|err\|info] text'; 'info' lines show the command, exit code and crashes). These describe this server's session, else the account's session on page_path, else its only one. sessions (mod #159) lists all running sessions of the account: session, page, currentPage, suite, busy, startedAt. busy=true means the process is still working on a call that timed out: wait and call this again until busy is false, or abort with fitnesse_debug_end(abort=true). known_to_this_server=false with running=true means someone else's session (or one from before a restart): the other debug tools refuse to touch it until you call this with adopt=true (with several sessions: plus session=<id> from 'sessions'). Only adopt a session you are meant to continue. |
| `fitnesse_table_source` | read | – | Reads a wiki page as its tables and the text between them, for changing single tables with fitnesse_table_save, fitnesse_table_insert and fitnesse_table_delete. Result: tables (wiki markup of each of the page's own tables; tables from included pages and tables nested in cells are not counted) and texts, where texts[i] is the text before tables[i] and the last text follows the last table. Its indices differ from fitnesse_debug_page_tables', which also counts SetUp, TearDown and included pages. Does not need a debug session. |
| `fitnesse_debug_end` | test | – | Ends the debug session: the running test's tear down (and, in a suite, the suite tear down) run, then the test process stops. Returns the tear-down result, the remaining log lines and page_totals (counts per page). Call it whenever you are done. abort=true stops the process immediately without tear down; it works even while another call is still running. Use it when the session hangs or busy stays true. |
| `fitnesse_debug_run_page` | test | – | Runs the tables of a test page in the debug session, exactly as a normal test run would send them (SetUp, TearDown and included pages included): all of them, or only the indices given in 'tables' (see fitnesse_debug_page_tables), in the order given. Result as for fitnesse_debug_run_wiki. If page_path is not the page currently being tested, the current page's test is ended first (its tear-down result comes back as previous_page_teardown) and the new page's test begins. Calling it again for the same page continues that page's test, so you can run its tables in several steps; restart=true begins it afresh. setup_only=true runs just the SetUp (the tables of the included SetUp page): do this right after fitnesse_debug_start, before fitnesse_debug_run_wiki or inspect. A later call without tables then leaves the SetUp out (skipped_setup lists its indices) instead of running it twice; restart=true or another page runs it again. only_failures=true returns only the tables with a [fail] or [error] cell, for long pages. In a suite session, call it for each page with runnable=true from fitnesse_debug_start's 'pages', in that order. |
| `fitnesse_debug_run_wiki` | test | – | Runs FitNesse wiki tables in the debug session, e.g. '\|with browser\|'. Rows are '\|cell\|cell\|' lines; separate tables with an empty line. Variables of the current page like ${BASE_URL} are resolved. The page's SetUp and TearDown are NOT added: run the SetUp first with fitnesse_debug_run_page(setup_only=true), otherwise the defined actions, the browser and fixtures it provides are missing. State carries over between calls: a browser opened in one call is still open in the next. All tables of one call run before the result comes back; it can take minutes (up to ~10). Result: 'tables' holds every table as text, one row per line; a cell's outcome is prefixed: [pass] check passed, [fail] check failed (the cell shows expected and actual), [error] exception (message and shortened stack trace), [ignore] not run. Cells without prefix are plain input. 'counts' are this call's right/wrong/ignores/exceptions; 'page_totals' add up all calls since the current page's test began. Below each table come what belongs to it: folding areas after it ('after: <title>', e.g. FitLibrary's show after or logs), links ('link in row R, column C: text -> url') and images. Inline screenshots ('[image N]' in a cell) are attached as image content (at most 4 per call); 'images' lists which one is where. Find the available keywords and their exact wording with fitnesse_debug_inspect(kind='keywords') before writing tables. restart=true first ends the running test (its tear down runs, result in previous_page_teardown) and begins it afresh: use it for a clean state. |
| `fitnesse_debug_start` | test | – | Starts a debug session for stepwise testing on a KDTA FitNesse: a test process that stays alive between calls, so you can run tables one call at a time and the state (open browsers, objects in scope, variables) carries over from one call to the next. Use it to try out steps, build a new test, or step through a failing one; for a plain complete run use fitnesse_run_test instead. Nothing is written to the test history. The page decides which fixtures and variables are available, so start on the test page (or, with suite=true, on the suite page) you want to work on. Typical flow: fitnesse_debug_start -> fitnesse_debug_run_page(setup_only=true) -> fitnesse_debug_inspect(kind='keywords' or 'definedActions') -> fitnesse_debug_run_wiki or fitnesse_debug_run_page, repeatedly -> fitnesse_debug_end. Run the SetUp first: defined actions, the browser and often fixtures only exist once it has run. One session per page and FitNesse account (forks before mod #159: one per account). If one is already running on this page (possibly a person working in the browser), this fails and says so: then continue it with fitnesse_debug_status(adopt=true, session=...) or end it. Sessions on other pages are not affected. This server works with one session at a time: end its own before starting another. Use replace=true only when told to: it kills the running session without tear down, and a browser tab on it then shows 'replaced'. With suite=true the result contains 'pages': the suite's pages in run order, each with path, kind (test, suiteSetUp, suiteTearDown) and runnable (false = cannot run in this session; skip it). Always end the session with fitnesse_debug_end when done: it occupies a server slot and browsers until then. |
| `fitnesse_table_delete` | write | – | Removes table index from the page. Saves the page for real (recent changes): change only pages you are asked to change. original is tables[index] or texts[index] from fitnesse_table_source, unchanged; if the page has changed since, this fails: read it again and redo the change. The result's source is the page after the change: take the next original and indices from it. A running debug session sees the change when the tables run again. |
| `fitnesse_table_insert` | write | – | Inserts new table(s) before table index, into the text in front of it: at the end of that text, or with start=true at its beginning; index = number of tables appends them at the end of the page. Saves the page for real (recent changes): change only pages you are asked to change. original is tables[index] or texts[index] from fitnesse_table_source, unchanged; if the page has changed since, this fails: read it again and redo the change. The result's source is the page after the change: take the next original and indices from it. A running debug session sees the change when the tables run again. |
| `fitnesse_table_move` | write | – | Moves table index to position to (counted before the move) in one save: into the text in front of table to, at its end, or with start=true at its beginning; to = number of tables moves it to the end. Saves the page for real (recent changes): change only pages you are asked to change. original is tables[index] or texts[index] from fitnesse_table_source, unchanged; if the page has changed since, this fails: read it again and redo the change. The result's source is the page after the change: take the next original and indices from it. A running debug session sees the change when the tables run again. |
| `fitnesse_table_move_text` | write | – | Moves texts[index] next to texts[to] in one save: after it, or with start=true in front of it. Saves the page for real (recent changes): change only pages you are asked to change. original is tables[index] or texts[index] from fitnesse_table_source, unchanged; if the page has changed since, this fails: read it again and redo the change. The result's source is the page after the change: take the next original and indices from it. A running debug session sees the change when the tables run again. |
| `fitnesse_table_save` | write | – | Replaces table index of a page with new wiki markup; with last, replaces tables index..last together with the text between them (e.g. a defined action spread over several tables). Editing a defined action: take page, index, last and original from fitnesse_debug_defined_action_source and pass reload_defined_actions=true. The running session then loads the page's defined actions again and runs the new version at once. The result has 'reload': reloaded (true = loaded), definedActions (the page's actions as now loaded), and if reloaded is false the reason, or error/code and the tables of the failed load. The page is saved either way: fix the definition and save again, or run fitnesse_debug_run_wiki('\|define actions at\|.<page>\|') once the page is right. Saves the page for real (recent changes): change only pages you are asked to change. original is tables[index] or texts[index] from fitnesse_table_source, unchanged; if the page has changed since, this fails: read it again and redo the change. The result's source is the page after the change: take the next original and indices from it. A running debug session sees the change when the tables run again. |
| `fitnesse_table_save_text` | write | – | Replaces texts[index], the wiki text in front of table index (one more after the last table), e.g. headings, comments, collapsible sections. Refuses text that would remove or change a table; tables in the new text are added (result: added, their number). Saves the page for real (recent changes): change only pages you are asked to change. original is tables[index] or texts[index] from fitnesse_table_source, unchanged; if the page has changed since, this fails: read it again and redo the change. The result's source is the page after the change: take the next original and indices from it. A running debug session sees the change when the tables run again. |
