# FitNesse MCP – tools, gates and descriptions (61)

Gates: mode (read/write/test) must be in FITNESSE_TOOLSETS; area complete/debug must be named as well; extra env gates as listed.


## standard

| Tool | Mode | Extra gate | Description |
|---|---|---|---|
| `fitnesse_download_file` | read | FILES_ROOT | Reads a file of the files section: an image comes back as an image, anything else as a resource with its content. |
| `fitnesse_get_page_data` | read | – | Returns the wiki text of a page (body), plus edit_time and ticket_id. Pass both to fitnesse_save_page_content when saving a change based on this text: if someone else saved the page in between, the save then fails instead of overwriting their change. Text of included pages (SetUp, !include) is not part of it. |
| `fitnesse_get_page_history` | read | – | Test history of a page, condensed. Without result_date: the page's runs (runs: date, result_date, pass, fail). With result_date (yyyyMMddHHmmss from runs, or 'latest'): that run. For a suite: final_counts and pages (page, outcome, counts, result_date; failed_pages lists the red ones): call again with a failing page and its result_date. For a test page: outcome, counts and tables, only the tables with a [fail] or [error] cell, cells prefixed [pass]/[fail]/[error]/[ignore]. With compare_to (a second result_date; result_date then defaults to 'latest'): what differs between the two runs. Test page: differences, the tables whose rows are not the same in both, each as a diff (+ lines are from run, - lines from compared_to). Suite: the pages whose outcome differs. raw=true returns FitNesse's XML instead. |
| `fitnesse_get_properties` | read | – | Returns the properties of a page as JSON (body): its type (Test, Suite; neither = static), the flags for the actions shown (Edit, Versions, Properties, Refactor, WhereUsed, RecentChanges, Files, Search), the security flags (secure-read, secure-write, secure-test), Prune (skipped in suite runs), and Help and Suites (tags) when set. Change them with fitnesse_save_properties. |
| `fitnesse_get_suite_overview` | read | – | The latest result of each test page of a suite, without running anything: summary (passed, not_run, failed), pages (page, outcome, result_date) and failed_pages. For why a page failed, call fitnesse_get_page_history(page, result_date). Takes the same test selection as fitnesse_run_suite. raw=true returns FitNesse's HTML instead. These are the stored results: after a run of your own, check that result_date is from that run; an older one means the run did not finish or was not stored. |
| `fitnesse_get_variables` | read | – | The variables a page can use as ${NAME}, its own and those inherited from parent pages: variables (name, value, location = the page that defines it; none for FitNesse's own). Values of passwords, tokens and the like are masked as ***. |
| `fitnesse_list_files` | read | FILES_ROOT | Lists a directory of the files section (uploads, screenshots, reports) as JSON (body): its files and subdirectories. |
| `fitnesse_list_names` | read | – | Lists the child pages of page_path (default: the top level) as a list of names (body). recursive=true lists the whole subtree as paths relative to page_path. Use it to find pages; fitnesse_search finds them by content. |
| `fitnesse_page_versions` | read | – | The saved versions of a page's wiki text. Without version: current (who saved the page last, and when) and versions (version, author, age), newest first; these are earlier states, the newest need not equal the current page. With version: that version as rendered text (content). With version and compare_to (another version, or 'latest' for the current page): diff, a unified diff of the wiki text (- lines are from version, + lines from compare_to). A version id ends with the time it was saved (yyyyMMddHHmmss). fitnesse_rollback_version makes a version the current one again. |
| `fitnesse_search` | read | – | Finds pages by name (search_type='title') or by content (search_type='content'). Result: matches (page, type Test/Suite, tags, last_modified) and count. Both are plain text matches, not regular expressions; a title match is any name containing the search_string. method_search=true (content only) finds the pages that use a method or scenario: give a wiki line that evaluates to it, e.g. '\|click\|x\|'. Searches page_path and its children; search_scope names an ancestor page instead, or 'root' for the whole wiki (a content search over the whole wiki can take minutes). |
| `fitnesse_run_suite` | test | – | Runs the test pages below a suite page and returns FitNesse's report (body). Narrow the selection with tags (suite_filter, run_tests_matching_all_tags, exclude_suite_filter), first_test, or a partition (partition_count with partition_index). The run is stored: fitnesse_get_suite_overview(page_path) then shows each page's outcome, fitnesse_get_page_history a failing page's tables. Do not combine nohistory with format='xml': that report is built from the history. A run that takes longer than the server's run timeout fails here but may go on in FitNesse: fitnesse_stop_test stops it. |
| `fitnesse_run_test` | test | – | Runs a test page from start to end and returns FitNesse's report (body): format 'xml' has every table with its results and can be large. Unless nohistory=true the run is stored: fitnesse_get_page_history(page_path, result_date='latest') then shows it condensed, with only the failing tables. A run that takes longer than the server's run timeout fails here but may go on in FitNesse: fitnesse_stop_test stops it. To step through a failing test and try out fixes, use fitnesse_debug_start. |
| `fitnesse_stop_test` | test | – | Stops running test and suite runs of this FitNesse, whoever started them: all of them, or the one with test_process_id. |
| `fitnesse_add_child_page` | write | – | Creates a page below parent_page_path with the given wiki text. page_type makes it a Test page (can run), a Suite (runs its child pages) or Static; without it FitNesse decides by the name (e.g. a name starting or ending with Test). Result: ok, status and a short message; read the page back with fitnesse_get_page_data. |
| `fitnesse_create_dir` | write | FILES_ROOT | Creates the directory dirname in a directory of the files section. |
| `fitnesse_delete_file` | write | FILES_ROOT | Deletes a file, or a directory with everything in it, from a directory of the files section. No undo. |
| `fitnesse_delete_page` | write | – | Deletes the page together with all its child pages. Only on request: there is no undo. |
| `fitnesse_move_page` | write | – | Moves the page with its child pages below another parent page; its name stays. To rename it, use fitnesse_rename_page. |
| `fitnesse_rename_file` | write | FILES_ROOT | Renames a file or directory of the files section within its directory. |
| `fitnesse_rename_page` | write | – | Gives the page a new name below the same parent; its child pages stay with it. To move it elsewhere, use fitnesse_move_page. |
| `fitnesse_replace` | write | – | Replaces text in the selected page and all its children and saves every changed page; returns an HTML table of the changed pages. Text replace: search_string is a regular expression. method_replace=true: search_string is a wiki line that evaluates to a method or scenario (e.g. '\|click\|x\|'). search_scope limits it to an ancestor page or 'root'. Try the search with fitnesse_search first: this cannot be undone in one step. |
| `fitnesse_rollback_version` | write | – | Makes a saved version the page's current content again. version is an id from fitnesse_page_versions; look at what changes first with fitnesse_page_versions(page_path, version, compare_to='latest'). |
| `fitnesse_save_account` | write | ALLOW_ACCOUNT_ADMIN | Changes FitNesse accounts (responder=saveAccount), as the account this server logs in with. action='change_password': new password for that account (current_password, new_password). 'create_user' and 'delete_user' need the admin user: user_name, plus user_password for create_user. Only on explicit request. |
| `fitnesse_save_page_content` | write | – | Saves the wiki text of a page, replacing all of it. Read it first with fitnesse_get_page_data and pass that call's edit_time and ticket_id: if someone else saved the page since then, nothing is saved and the call fails; read the page again, merge, and save again. Without edit_time the save overwrites whatever is there. The page's help text and tags are kept unless help_text or suites are given; an empty string removes them. |
| `fitnesse_save_properties` | write | – | Saves page properties via POST: pageType, attribute flags, Suites tags and HelpText. FitNesse resets every attribute that is not sent, so each argument left out keeps the page's current value; `attributes` is the complete list of flags that end up set. Pass an empty string or list to clear a value. |
| `fitnesse_shutdown` | write | ALLOW_SHUTDOWN | Shuts the FitNesse server down through the shutdown responder. |
| `fitnesse_upload_file` | write | FILES_ROOT | Stores a file in a directory of the files section, replacing a file of the same name. Give the content as text (content) or base64-encoded for binary files (content_base64). |

Returns HTML; values of secrets (Authorization, API keys, tokens, cookies, passwords) are masked as ***. |

| `fitnesse_get_raw` | read | – | Returns the raw wiki text of the selected page using the raw responder. |
| `fitnesse_get_refactor_screen` | read | – | Displays the refactoring screen for the selected page. |

| `fitnesse_get_test_history` | read | – | Displays current test history for a page subtree or all history. Returns XML; results and trim only shape the HTML view (format='html'). |
| `fitnesse_partition_preview` | read | – | Previews how fitnesse_run_suite(partition_count=...) distributes the suite's tests over partitions, without running them. Takes the same test selection as fitnesse_run_suite. Returns tab-separated lines (format='tsv', default) or HTML. |
| `fitnesse_search_properties` | read | – | Finds pages by their properties (responder=searchProperties; the deprecated executeSearchProperties is the same responder). Every criterion left out is ignored. page_types: pages of any of these types. suites: pages with any of these tags. actions / security / special: each listed attribute must be set and each unlisted one of that group must not be, so list exactly the combination you want ('Any' ignores the group). special covers SetUp/TearDown pages: listed kinds are included, unlisted excluded. prune=true finds only pages marked as skipped. Searches page_path and its children unless search_scope names an ancestor or 'root'. Navigation actions (RecentChanges, Files, Search) are only matched by FitNesse 20261101 or later. Result: matches (page, type, tags, last_modified) and count. |

| `fitnesse_import_and_view` | write | – | As fitnesse_import_pages, but answers with the imported page's view. |
| `fitnesse_import_pages` | write | – | Imports the pages below remote_url, a page of another FitNesse, as children of page_path. auto_update=true imports them again whenever the page is viewed. |
| `fitnesse_manage_symlink` | write | – | Manages the symbolic links of a page, which show another page as its child. Create: link_name and link_path (the target page). Remove: removal, the link's name. Rename: rename, the link's name, and newname. |
| `fitnesse_publish` | write | – | Publishes the site as static HTML files using destination as the output root path. |
| `fitnesse_purge_history` | write | – | Deletes the test history older than `days` days of a page and its children; purge_global=true that of all pages. Cannot be undone. |

## debug

| Tool | Mode | Extra gate | Description |
|---|---|---|---|
| `fitnesse_debug_defined_action_source` | read | – | Reads the wiki of a defined action for editing, fresh from the page that defines it: the definition block as FitLibrary reads it, from its header table to the next ---- line. A definition is a signature table \|greet\|name\| (plain names) plus body tables using @{name}, ended by ----. Result: page, index, last and original, ready for fitnesse_table_edit(action='save', page_path=page, index=index, last=last, original=original, wiki=<new>, reload_defined_actions=true). Needs a debug session that has loaded the action, or page_path, the page that defines it. To try a fix before saving, run the body's rows with fitnesse_debug_run_wiki, its parameters replaced by values. |
| `fitnesse_debug_inspect` | read | – | Looks into the debug session. kind: - 'keywords': the keywords usable in tables now. Without filter only the categories and their sizes. With filter (a word such as 'click', or a category; help texts are searched too) the matching entries: syntax, where %1, %2 are the parameter cells ('click %1' -> '\|click\|//button\|'), parameters (label, options), returnType and tableItems (the rows the keyword expects in the rest of its table). Write the syntax as given, !-JavaScript-! included. generated=true: a method without keyword annotation, callable as written. details=true adds the help texts. Defined actions are not in it. - 'definedActions': the defined actions the session has loaded with \|define actions at\| (usually in the SetUp): action (the call), parameters, note, deprecated, author, page and overrides. filter searches these, not the body: read that with fitnesse_debug_defined_action_source. - 'dynamicVariables': the variables set during the test (name, value). - 'scope': the objects whose keywords are available, in lookup order (level, name, class, depth). - 'liveView': the open remote browsers and live_view_url, a link where a person can watch the browser. |
| `fitnesse_debug_page_tables` | read | – | Lists the tables a run of the page executes, in order, with those of its SetUp, TearDown and included pages: index, rows, first_row, source_page and source_index. The indices are for fitnesse_debug_run_page(tables=[...]); setup_tables and teardown_tables say which of them are the SetUp's and the TearDown's. To edit a table, pass its source_page and source_index to fitnesse_table_source and fitnesse_table_edit, never its index: those count only a page's own tables. included=true: the table is on an included page (e.g. the SetUp), and editing it changes every page that includes it. Needs a debug session; without page_path the page being tested. |
| `fitnesse_debug_read_link` | read | – | Reads a file a debug result links to: the screenshot ('Screen', /files/screenCaptures/...) or the page source at the failure ('HTML', /files/htmlSource/...) that KDTA links from a failing table. An image comes back as an image. HTML and text come without scripts, styles and comments: with filter only the places that contain it, to check a locator against the page as it was (an id, a class, a visible text); without filter the beginning and the length. Only links into this FitNesse's files section; needs no session. |
| `fitnesse_debug_status` | read | – | Shows the debug session and the new entries of the test process's log since the last call. Answers at once, also while another call is still running a long table: use it to watch progress. Result: running, page (where the session started), currentPage, suite, busy, idleSecondsLeft (the session ends itself after this idle time), known_to_this_server, sessions (all running sessions of the account) and log.lines, one log entry each ('time [out\|err\|info] text'; values of secrets are masked as ***). log_level, log_filter and log_newest narrow the log; the entries they leave out (left_out, skipped) count as read. busy=true: the process is still working on a call that timed out. Call this again until it is false, or fitnesse_debug_end(abort=true). known_to_this_server=false with running=true: someone else's session, or one from before a restart; the other debug tools refuse to touch it, and this server does not take it over: leave it alone, it ends itself when idle. |
| `fitnesse_debug_steps` | read | – | Lists the steps noted while building a test: every fitnesse_debug_run_wiki call whose tables all passed (unless run with record=false), in order: step, page, wiki. 'wiki' joins them, ready to save on the page with fitnesse_table_edit(action='insert'). drop forgets single steps (tries that don't belong in the test), clear=true all of them, e.g. after saving. They outlast fitnesse_debug_end; a new fitnesse_debug_start clears them. |
| `fitnesse_table_source` | read | – | Reads a wiki page as its tables and the texts between them, for fitnesse_table_edit and fitnesse_table_edit_text. Result: tables (the wiki of each of the page's own tables; tables of included pages and tables nested in cells don't count) and texts: texts[i] is the text in front of tables[i], the last one follows the last table. These indices are not those of fitnesse_debug_page_tables, which also counts SetUp, TearDown and included pages. Needs no debug session. |
| `fitnesse_debug_end` | test | – | Ends the debug session as a normal run ends: first the current page's TearDown tables that have not run yet (teardown), on a single test page also its SuiteTearDown (suite_teardown), then the test process stops. Call it whenever you are done. Result: the tear down's tables (FitLibrary's own 'Messages in storytest tear down' is always among them), the last unread log entries (log; log_omitted counts those left out) and page_totals, the counts per page. Take the outcome from page_totals: the 'Exit code' in the log is the sum of the wrong and exception counts of everything the session ran, not an outcome. abort=true stops the process at once without tear down, also while another call is running: use it when the session hangs or busy stays true. |
| `fitnesse_debug_run_page` | test | – | Runs the tables of a test page in the debug session as a normal run would send them (SetUp, TearDown and included pages included) and stops after the first table with a [fail] or [error] cell, like a debugger: the rest of the page, its TearDown included, has not run, and the browser and state are as the failure left them. On a stop the result has stopped_at (index, source_page, source_index, text_before, wiki, log), next_table and, when an element failed, its screenshot as an image; its 'HTML' link, the page source then, is read with fitnesse_debug_read_link(url, filter=...). Not for \|check\|title\|. Try corrected versions of stopped_at.wiki with fitnesse_debug_run_wiki until one passes and save that one with fitnesse_table_edit(source_page, source_index, original=stopped_at.wiki), or report that there is no fix (e.g. the application is wrong). Then call this again without arguments: it continues at next_table. page_done=true: all tables ran. Result tables as in fitnesse_debug_run_wiki. setup_only=true runs just the SetUp: do that right after fitnesse_debug_start; a later run of the page then leaves the SetUp out. tables=[...] runs only those indices of fitnesse_debug_page_tables and does not move next_table. On a single test page the first call runs its SuiteSetUp before (suite_setup), which stops at a failure the same way. page_path other than the current page (a test page, or one of fitnesse_debug_start's pages) first ends the current page's test as a normal run would, with its TearDown tables that have not run yet (previous_page_teardown), then begins the new one. In a suite session call this for each runnable page in order, moving on once page_done is true. |
| `fitnesse_debug_run_wiki` | test | – | Runs wiki tables in the debug session without saving anything, e.g. '\|with browser\|'. Variables of the current page such as ${BASE_URL} are resolved. The page's SetUp and TearDown are not added: run the SetUp first with fitnesse_debug_run_page(setup_only=true). Take the keywords' exact wording from fitnesse_debug_inspect(kind='keywords'). All tables of a call run before the result comes back, which can take minutes. Result: tables, each as text with one row per line. A cell's outcome is prefixed: [pass], [fail] ('<value> expected ⏎ <value> actual'), [error] (an exception), [ignore] (not run); cells without prefix are input. Below a table come its folding areas ('after: <title>'), links and images; screenshots are attached as images (at most 4 per call). counts are this call's, page_totals those since the page's test began. A call whose tables all pass is noted as a step (step; see fitnesse_debug_steps). A [pass] on a click only means the call returned: check its effect (URL, a text, an element's visibility) before the next step. Every table with \|with browser\| starts its own browser, which stays in the grid until fitnesse_debug_end: start it once in the SetUp with \|add global\|with browser\|. |
| `fitnesse_debug_start` | test | – | Starts a debug session on a KDTA FitNesse: a test process that stays alive between calls, so tables run one call at a time and the state (open browsers, objects in scope, variables) carries over. Use it to try out steps, build a new test or step through a failing one; for a plain run use fitnesse_run_test. Nothing is written to the test history. Start on the test or suite page you want to work on: it decides which fixtures and variables there are, and its type the kind of session. Then: fitnesse_debug_run_page(setup_only=true), since defined actions, the browser and often fixtures only exist once the SetUp has run -> fitnesse_debug_inspect -> fitnesse_debug_run_wiki or fitnesse_debug_run_page, repeatedly -> fitnesse_debug_end, always: the session holds a server slot and browsers until then. Result: suite (true/false) and pages in run order (path, kind test/suiteSetUp/suiteTearDown, runnable). Suite session: call fitnesse_debug_run_page for each page with runnable=true, in that order. Test page: its SuiteSetUp and SuiteTearDown run by themselves, with the first fitnesse_debug_run_page and with fitnesse_debug_end. Fails if a session is already running on this page (maybe a person's, in the browser): use another page or wait; this server does not take over sessions it did not start. This server holds one session at a time: end it before starting another. |
| `fitnesse_table_edit` | write | – | Changes the tables of a wiki page, one change per call. action: - 'save': replaces table index with wiki; with last, tables index..last and the text between them, e.g. a defined action of several tables. - 'insert': puts the table(s) of wiki in front of table index; index = number of tables appends them to the page. - 'delete': removes table index. - 'move': moves table index in front of table to, counted before the move; to = number of tables moves it to the end. insert and move put the table at the end of the text in front of the target table, with start=true at its beginning. Saves the page for real: change only pages you are asked to change. original is the current wiki from fitnesse_table_source, unchanged; if the page has changed since, the call fails: read it again and redo the change. The result's source is the page after the change (tables and texts, as fitnesse_table_source): take the next original and the indices from it. A running debug session sees the change when the tables run again. A defined action: signature table \|greet\|name\| plus body tables using @{name}, a ---- line after each definition. A reload adds, it never removes: after a wrong format start a new session. |
| `fitnesse_table_edit_text` | write | – | Changes the wiki text between the tables of a page (headings, comments, collapsible sections), one change per call. texts[index] of fitnesse_table_source is the text in front of table index; the last one follows the last table. action: - 'save': replaces texts[index] with wiki. Tables in the new text are added (result: added); text that would change or remove a table is refused. - 'move': moves texts[index] behind texts[to], with start=true in front of it. Saves the page for real: change only pages you are asked to change. original is the current wiki from fitnesse_table_source, unchanged; if the page has changed since, the call fails: read it again and redo the change. The result's source is the page after the change (tables and texts, as fitnesse_table_source): take the next original and the indices from it. A running debug session sees the change when the tables run again. |
